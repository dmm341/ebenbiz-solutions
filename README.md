# Ebenbiz Solutions Website

Official website for **Ebenbiz Solutions**, showcasing our full portfolio of products and professional services:
- **Ebenbiz ERP**: Cloud POS, multi-branch inventory, double-entry accounting, invoicing, and reporting.
- **Hardware Supply**: POS terminals, receipt printers, barcode scanners, computers, laptops, and networking peripherals.
- **Inventory Services**: Physical stock taking, stock audits, inventory reconciliation, and management contracts.
- **Hardware Maintenance**: Scheduled preventive maintenance, PC/printer repair, dust cleaning, and IT support contracts.

## Tech Stack
- React 19 + Vite
- Tailwind CSS v4
- Lucide React Icons
- Configured for instant deployment on **Vercel**

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
